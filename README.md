# 🚌 Bus Management System

A comprehensive **Bus Management System** built in C for Windows. It provides a complete solution for managing bus bookings, user accounts, routes, schedules, and generating reports with both user and admin interfaces.

## ✨ Features

### 🔐 User Management
- User registration with email and password
- Login using email or User ID
- Password reset functionality
- View all users (Admin)
- Add/Remove users (Admin)

### 🚌 Bus Management
- Add new buses with details (name, number, type, seats, price)
- View all buses in formatted table
- Edit or delete existing bus entries

### 📅 Route & Schedule Management
- Add daily schedules for routes
- Update existing schedules
- View all schedules in structured table format

### 🎫 Booking System
- Cancel bookings with refund tracking
- View all active bookings
- View canceled bookings history
- Auto-generate booking password
- Print receipt/ticket (saves as `ticket.txt`)
